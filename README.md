1. What is the difference between var, let, and const?
   Ans: var -> function scoped, can redeclare and reassign ,
        let -> block scoped, can reassign but cannot redeclare ,
        const -> block scoped, cannot reassign or redeclare
2. What is the spread operator (...)?
   Ans:The spread operator (...) is used to expand or spread elements of an array or object.
3. What is the difference between map(), filter(), and forEach()?
   Ans:map() -> creates a new array by applying a function to each element.
       filter() -> creates a new array with elements that pass a condition.
       forEach() -> is used to loop through an array and does not return a new array.
4. What is an arrow function?
   Ans: An arrow function is a shorter way to write a function in JavaScript and uses the => syntax.
5. What are template literals?
   Ans:Template literals are strings enclosed by backticks (`) instead of quotes (' or "). They allow interpolation of variables, multi-line strings, and expressions easil.
